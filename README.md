# 나만의 캘린더 앱 (My Calendar App)

Python(Flask)과 JSON 파일만으로 만드는 개인용 캘린더 & 메모 웹앱입니다.
데이터베이스 없이 `data.json` 파일 하나에 모든 메모를 저장합니다.

## 주요 기능 (목업 기준)

- 📅 **캘린더 뷰**: 한 달 단위로 날짜를 보여주고, 메모가 있는 날짜는 표시(마킹)됩니다.
- 🔍 **키워드 검색**: 제목/내용, 태그, 날짜 키워드로 메모를 검색합니다.
- 📝 **메모 추가**: 특정 날짜에 새 메모(제목 + 내용)를 작성합니다.
- 📖 **메모 상세 페이지**: 캘린더에서 날짜를 클릭하면 해당 날짜의 메모 목록/상세를 볼 수 있습니다.
- 📚 **사이드바**: 전체 메모를 최신순 등으로 모아서 트리 뷰로 보여주는 목록 영역입니다.

## 기술 스택

| 영역 | 기술 |
|------|------|
| 백엔드 | Python 3, Flask |
| 데이터 저장 | JSON 파일 (`data.json`) |
| 프론트엔드 | HTML, CSS, (필요 시 최소한의 JS) — Flask 템플릿(Jinja2) 사용 |

## 프로젝트 구조 (예정)

```
calendar_app/
├── app.py              # Flask 앱 진입점 (라우팅)
├── data.json            # 메모 데이터 저장 파일
├── requirements.txt      # 의존성 목록
├── templates/            # HTML 템플릿 (Jinja2)
│   ├── base.html
│   ├── calendar.html      # 캘린더 메인 화면
│   └── day.html          # 날짜별 메모 상세 화면
├── static/               # CSS, JS, 이미지
│   └── style.css
└── README.md
```

## 데이터 구조 (예정)

메모는 `data.json`에 날짜별 리스트 형태로 저장할 예정입니다. 예:

```json
{
  "2026-09-23": [
    {
      "id": "uuid-string",
      "title": "팀 회의",
      "content": "3분기 목표 점검",
      "tags": ["공부"]
      "attachments": ["2026-09-23T10:00:00"]
    }
  ]
}
```

## 실행 방법 (추후 단계 완료 후)

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속

## 개발 단계 (로드맵)

- [x] 1단계: README.md 작성 (프로젝트 개요 정리)
- [ ] 2단계: 터미널 버전 (화면 없이 데이터만)
    -# 배우는 것: 딕셔너리, 리스트, JSON 파일 저장/불러오기
    화면 없이 터미널에서만 동작하는 버전을 먼저 만듦. 메모 추가 / 수정 / 삭제 / 날짜로 조회, 그리고 data.json 저장·불러오기. 위의 "data.json 예시"와 같은 구조를 씀. 이 단계의 함수들을 나중에 웹에서도 그대로 재사용하게 됨.
- [ ] 3단계: Flask로 캘린더 화면
    -# 배우는 것: 웹 서버, 라우트, HTML 표 만들기
    월간 캘린더 표를 웹페이지로 만듦. 메모가 있는 날짜 칸에는 제목·해시태그·📎(첨부여부)를 표시하고, 날짜를 클릭하면 그 메모의 상세 페이지로 이동하게 함. 이전/다음 달 이동 버튼도.
- [ ] 4단계: 검색 기능
    -# 배우는 것: 탐색 알고리즘, 인덱스, 속도 비교(Big-O 체감)
    날짜 검색 / 태그 검색 / 내용 검색 3가지를 만듦. 태그 검색은 ① 전체를 for문으로 도는 버전 → ② 태그 인덱스 딕셔너리를 미리 만들어 두는 버전 순서로 만들고, 가짜 글 1만 개를 자동 생성해서 두 방식의 검색 시간을 잼 (time 모듈). 결과를 README에 기록!
- [ ] 5단계: 트리뷰 (글 모아보기)
    -# 배우는 것: 트리 구조, 재귀 함수
    왼쪽 사이드바에 "연도 → 월 → 글" 접기/펼치기 트리를 만듦. 평면 딕셔너리를 중첩 딕셔너리로 바꾸는 함수 + 그걸 HTML로 그리는 재귀 함수, 두 개가 핵심.
- [ ] 6단계: 첨부파일
    -# 배우는 것: 파일 업로드, 데이터와 파일의 분리
    글 작성/수정 화면에서 파일을 업로드하면 attachments/ 폴더에 저장하고, JSON에는 경로만 기록함. 상세 페이지에서 첨부파일을 열어볼 수 있게.
